# 味蕾探险家 Agent

一个基于扣子（Coze）工作流的美食探索 Agent：上传冰箱食材照片或文字，自动识别食材、检索烹饪知识库，生成家常菜谱、营养分析和成品图。

## 功能
- 图片/文字识别食材
- 食材筛选：拆解食材名、纠正别名（如“西蓝花”→“西兰花”）、剔除水果饮料
- 知识库检索：混合检索 + 查询改写 + 结果重排
- 家常菜谱生成：只选用 2～6 种适合入菜的食材
- 营养分析：只使用知识库实际数据，缺少数据时明确标注为估算
- 生图提示词 + 成品图生成

## 文件说明
- `味蕾探险家-烹饪知识库.md`：上传到 Coze 知识库的原始文档，按食材组织（相克提示、营养成分、搭配建议、处理技巧）
- `workflow.md`：工作流节点结构和提示词，便于复现或备份

## 快速复现
1. 登录 [Coze](https://www.coze.cn)，新建工作流。
2. 新建知识库，上传 `味蕾探险家-烹饪知识库.md`。
3. 按 `workflow.md` 的节点顺序和提示词搭建工作流。
4. 点击“试运行”验证，确认后点击“发布”。

## 注意
- 知识库中的相克提示为常见饮食经验，不构成医疗建议。
- 营养数据为估算值，特殊体质或疾病人群请遵医嘱。
